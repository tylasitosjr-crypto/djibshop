Connexion Base de Données Cloud (Supabase)

Synchronisez votre catalogue en temps réel sur tous les téléphones et ordinateurs.

Comment créer la table dans Supabase en 1 clic :
Dans votre tableau de bord Supabase (SQL Editor), collez simplement : 
create table if not exists products (
  id text primary key,
  ref text,
  title text,
  category text,
  price numeric,
  original_price numeric,
  badge text,
  flash_sale boolean default false,
  flash_sale_ends text,
  bg_style text default 'studio-white',
  description text,
  images jsonb,
  sizes jsonb,
  total_stock integer,
  created_at timestamp with time zone default now()
);
